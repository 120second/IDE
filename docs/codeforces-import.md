# CF / 洛谷题目监听

在 LightCP 中打开一个文件夹，点击编辑器顶部的 **监听**（或在命令面板选择 **CF / 洛谷题目监听**）。选择 C++ 文件模板，默认使用已有的 **竞赛 C++ / Contest C++**，点击 **开启监听**。

首次使用时，在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)，然后从监听窗口 **复制安装地址**，在浏览器地址栏打开该地址并安装脚本。也可以点击 **复制油猴脚本**，粘贴到油猴的“添加新脚本”并保存。脚本源文件为 [`scripts/lightcp-codeforces.user.js`](../scripts/lightcp-codeforces.user.js)，同一个脚本同时支持 CF 和洛谷。已安装旧版的用户需重新打开安装地址更新到 **1.1.0**，或在原脚本编辑器中覆盖保存；无需安装第二个脚本。更新后刷新题目页。

开启监听后，脚本每 3 秒检查一次，只自动导入当前可见的 CF 或洛谷题目页。CF 题目下方、洛谷页面右下角的 **发送到 LightCP** 按钮可以随时手动发送。洛谷站内切换题目后也会导入新题。油猴菜单可以关闭或重新开启自动监听。脚本未连接到 IDE 时保持安静；手动发送失败会说明原因。

导入后会：

- 在开启监听时的工作区根目录创建 `A. 题目名称.cpp`，填入选择的文件模板。
- 同时保存 `A. 题目名称.md`，并将 Markdown 题面关联到代码文件，自动打开代码和读题面板。
- 保留公式、图片链接、输入输出说明、样例和注释，并将所有样例直接添加为启用的固定测试点。
- 洛谷文件以 `CF1A Theatre Square.cpp` 或 `P1001 A+B Problem.cpp` 等“题号 + 题名”命名，题面保存为同名 `.md`。
- 同一来源的题目再次发送会打开已有代码，不覆盖代码、题面、批注或样例；同名的其他文件会使用 ` (1)` 等后缀。CF 原站和洛谷翻译页分别保存，避免覆盖已有解答。

支持 Codeforces `/problemset/problem/编号/题号`、`/contest/编号/problem/题号` 和具有 HTML 题面的 `/gym/编号/problem/题号` 页面，包括 Codeforces 子域名。PDF-only Gym 题目暂不支持。提取浏览器已经显示的题面；不自动翻译。Markdown 文件是导入时题面的副本，读题面板后续编辑保存到本地题面存储。

支持 `www.luogu.com.cn/problem/题号` 和 `luogu.com.cn/problem/题号`，包括洛谷原生题目和 CF 搬运题。直接读取洛谷页面提供的原始 Markdown、公式、代码块及样例，**优先使用已有的中文翻译**；没有中文翻译时保留原题面。时限和内存显示页面提供的首个语言限制。站内切题时若初始页面数据过期，会在浏览器内请求同域题目页，使用已有登录状态；没有查看权限、未登录或验证页面不会生成空题面。该功能不自动翻译，也不读取题解。

关闭监听设置窗口不会停止监听。点击 **停止监听**、切换工作区或退出工作台会停止。重新启动 IDE 后需重新开启监听；油猴脚本只需安装一次。

本地桥接服务仅在开启监听时绑定 `127.0.0.1:27121`。油猴通过 [GM_xmlhttpRequest](https://www.tampermonkey.net/documentation.php#api:GM_xmlhttpRequest) 发送题面数据，不向 IDE 传递 Codeforces 或洛谷密码、Cookie。桥接服务不提供 CORS，通过脚本标识和每次监听生成的会话令牌校验请求，仅允许支持的 CF / 洛谷来源；接收端不会采用浏览器传来的文件路径。题面请求上限为 2 MB、样例上限为 100 组。若端口被其他程序占用，IDE 会显示开启失败的原因。
