# CF / 洛谷题目导入

在 LightCP 桌面版中打开一个文件夹，接收服务会自动就绪。浏览器安装脚本后，在 CF 或洛谷题目页按 **F10** 即可导入当前题面和样例，无需打开设置窗口或手动开启监听。默认使用已有的 **竞赛 C++ / Contest C++** 文件模板。

首次使用时，在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)，然后点击编辑器顶部的 **题目导入**（或在命令面板选择 **CF / 洛谷题目导入设置**），点击 **复制安装地址**，在浏览器地址栏打开该地址并安装脚本。也可以点击 **复制油猴脚本**，粘贴到油猴的“添加新脚本”并保存。脚本源文件为 [`scripts/lightcp-codeforces.user.js`](../scripts/lightcp-codeforces.user.js)，同一个脚本同时支持 CF 和洛谷。已安装旧版的用户需重新打开安装地址更新到 **1.2.1**，或在原脚本编辑器中覆盖保存；无需安装第二个脚本。更新后刷新所有已打开的题目页；请停用重复安装的旧脚本。新版 EXE 会拒绝旧版脚本的自动导入请求。

脚本仅在按 **F10** 时导入，页面提示和油猴说明菜单都不会发送题目。打开、刷新或切换题目页不会自动导入。F10 需要在浏览器题目页获得焦点时按下；带 Ctrl、Alt、Shift、Meta 的组合键和长按产生的重复按键不会触发导入。发送中会显示进度，失败时说明原因并允许重试。洛谷站内切换题目后再次按 F10，会读取当前题目。

需要更换 C++ 文件模板时，在 **题目导入** 中选择模板并点击 **保存模板**。当前会话后续导入以及切换工作区后继续使用该模板；重新启动 IDE 后恢复默认模板。

导入后会：

- 在当前工作区根目录创建 `A. 题目名称.cpp`，填入选择的文件模板。
- 同时保存 `A. 题目名称.md`，并将 Markdown 题面关联到代码文件，自动打开代码和读题面板。
- 保留公式、图片链接、输入输出说明、样例和注释，并将所有样例直接添加为启用的固定测试点。
- 洛谷文件以 `CF1A Theatre Square.cpp` 或 `P1001 A+B Problem.cpp` 等“题号 + 题名”命名，题面保存为同名 `.md`。
- 同一来源的题目再次发送会打开已有代码，不覆盖代码、题面、批注或样例；同名的其他文件会使用 ` (1)` 等后缀。CF 原站和洛谷翻译页分别保存，避免覆盖已有解答。

支持 Codeforces `/problemset/problem/编号/题号`、`/contest/编号/problem/题号` 和具有 HTML 题面的 `/gym/编号/problem/题号` 页面，包括 Codeforces 子域名。PDF-only Gym 题目暂不支持。提取浏览器已经显示的题面；不自动翻译。Markdown 文件是导入时题面的副本，读题面板后续编辑保存到本地题面存储。

支持 `www.luogu.com.cn/problem/题号` 和 `luogu.com.cn/problem/题号`，包括洛谷原生题目和 CF 搬运题。直接读取洛谷页面提供的原始 Markdown、公式、代码块及样例，**优先使用已有的中文翻译**；没有中文翻译时保留原题面。时限和内存显示页面提供的首个语言限制。站内切题时若初始页面数据过期，会在浏览器内请求同域题目页，使用已有登录状态；没有查看权限、未登录或验证页面不会生成空题面。该功能不自动翻译，也不读取题解。

关闭题目导入设置窗口不影响 F10 导入。切换工作区时会停止旧会话，并自动为新工作区准备接收，防止题目保存到旧目录。退出工作台会停止服务；重新启动 IDE 并打开工作区后自动恢复接收。油猴脚本只需安装一次。若状态未就绪，可在设置中查看错误并点击 **重试连接**。

本地桥接服务在打开工作区后自动绑定 `127.0.0.1:27121`。油猴通过 [GM_xmlhttpRequest](https://www.tampermonkey.net/documentation.php#api:GM_xmlhttpRequest) 发送题面数据，不向 IDE 传递 Codeforces 或洛谷密码、Cookie。桥接服务不提供 CORS，通过脚本标识和每次接收会话生成的令牌校验请求，仅允许支持的 CF / 洛谷来源；接收端不会采用浏览器传来的文件路径。题面请求上限为 2 MB、样例上限为 100 组。若端口被其他程序占用，IDE 会显示连接失败的原因。
