# 随机数据

在测试点面板点击 **随机数据**。左侧配置输入，右侧检查结构或生成结果；窄窗口自动调整布局。格式、范围、分布和固定种子设置按 C++ 文件自动保存，旧版保存的规则仍可继续编辑。

## 常用输入

直接选择 **数组、区间查询、树、图、矩阵、字符串、排列、整数行**。主要参数默认展开，改完范围就可以生成，无需逐项打开编辑窗口。其他格式中还提供带权树、单个整数等。替换或清空后，可点击 **恢复之前的格式**。

勾选 **多组测试 T** 会在当前格式外添加 T 和循环，保留内部范围；取消勾选则去掉这层。循环内每次都会重新生成 n、数组等内容。已有 T 组格式会自动识别。

**多组测试 T** 表示一份输入中的多个测试用例；工具栏 **组数** 表示生成几份独立输入文件，两者可以同时使用。

## 直接改参数

- 范围、长度和循环次数可填写整数、`1e9`、`1.5e3`、`10^9`、已定义变量以及加减乘除、取余和括号，例如 `3n`、`3*n`、`n*m`、`3n+1`、`(n+1)/2`。`3n` 表示 `3*n`，适用于字符串、数组长度等所有参数。运算遵循先乘除后加减；除法向零取整，例如 `7/2=3`。每步运算按 int64 精确处理，除零或溢出会报错。不执行脚本，不支持函数调用和一般乘方（仅支持 `10^9` 这类十进制简写）。
- 固定数值可以将上下界填写成同一个值。数组长度填写 `n`，会跟随前面实际生成的 n。
- 展开 **同行添加更多字段**，点击 **同行整数**，或一次输入 `x y z` 并按 Enter 添加多个变量。也可添加数组、字符串和排列，整数和数组能同处一行。
- 区间查询格式默认生成 `1 ≤ l ≤ r ≤ n`，r 的下界填写 `l`。变量只能引用前面已定义的整数；循环内定义的变量不会泄漏到外部。
- 使用连通图时，m 至少为 n−1，例如将 m 的下界填写 `n-1`、上界填写 `n`。图生成器会检查自环、重复边和边数是否可行。
- 填反范围或引用不存在的变量时，参数会标红并说明原因。数据规模超过生成器限制时也会给出提示。

## 生成、运行与复现

默认每次点击 **生成新数据** 都使用新种子。工具栏可设置 1～100 组，生成后在预览顶部切换组别。

预览中的 **固定此种子** 会锁定当前组；再次使用相同格式、分布和种子生成，可复现同样的数据。也可在生成设置里直接填写种子，输入后会自动锁定。取消 **固定种子** 后恢复每次生成新数据。

有预览时，**运行这组** 使用当前选中的输入；没有预览时可 **生成并运行**。**复制** 和 **存为测试点** 使用完整数据，即使大输入的屏幕预览被截断也不会丢失尾部。保存为固定测试点后，可在测试点面板填写期望输出。
