# LightCP v0.1.1-dev.2

Windows 开发预发布版，包含截至 2026-10-06 的功能与稳定性更新。

## 本次更新

- 对拍支持导出包含两份源码快照、失败输入、输出和编译参数的重放包；导入后在独立临时目录中编译并重放，结果一致时明确显示成功状态。
- 修复对拍实时进度事件、重复启动、保存源码期间取消，以及 Windows 临时目录短路径和 `..` 路径识别问题。
- 新增 Markdown/PDF 读题、圈画批注、浮动画板，以及可离线使用的题目工具。
- 社区支持个人主页、头像、用户搜索和私信；改进私信历史分页、未读处理和异步会话切换，避免中文输入法确认时误发送。
- 题面文字、批注和画板迁入 SQLite；文件改名同步迁移测试点、生成规则及关联笔记，保存失败会提示并保留待重试内容。
- 编译支持取消与 120 秒超时；改进大量输出、停止、运行超时和 Windows 子进程树回收。
- 修复 clangd 工作区与诊断路径识别，并加入前端、Rust、C++ 工具链、Python 和数据库迁移的 GitHub Actions 检查。

## 下载与使用

- 安装版：`LightCP_0.1.1-dev.2_x64-setup.exe`，安装到当前用户目录，并创建桌面及开始菜单快捷方式。
- 便携版：`LightCP_0.1.1-dev.2_x64-portable.exe`，下载后直接运行。
- `SHA256SUMS.txt` 提供两个 EXE 的 SHA-256 校验值。

需要 Windows 10/11 与 Microsoft Edge WebView2 Runtime。编译、调试和 C++ 语言服务分别需要 g++、GDB 与 clangd，可在设置中配置路径。

这是开发预发布版。重放包当前只保存两份单文件源码，不收集自定义头文件或外部资源；使用不同编译器或系统可能影响重放结果。详见 [重放包说明](../stress-replay.md)。

社区分页、限流等功能需要配套服务端更新；发布客户端和服务端源码不等于已部署远程服务器。升级前建议备份应用数据与 WebView 数据，PDF 仍保存在 WebView IndexedDB。

## 验证

本轮功能代码通过 207 项前端测试、87 项 Rust 测试及 24 项服务端测试；Rust 格式与 Clippy 严格检查通过。此次仅调整发布版本号，已重新通过 Svelte/TypeScript 检查和 Tauri Windows 发布构建。
