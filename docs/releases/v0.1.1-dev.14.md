# LightCP v0.1.1-dev.14

Windows 开发预发布版，2026-10-23。包含自 dev.5 发布以来累计的界面改进与编译、诊断系统修复。

## 界面与使用体验

- 新增可在设置中切换的 Sublime 风格：Monokai 风格代码配色、左侧文件树，以及右侧测试点/题面工具。右侧页面标签与代码文件标签位于同一行。
- Sublime 整体背景透明度可实时调整并自动保存；文字保持独立显示，默认透明度 3%，支持完全不透明。
- 右侧测试点采用紧凑的 CPH / FastOlympicCoding 风格，支持编辑、运行、批量运行、判定、耗时和输出查看；切换页面保留编辑内容。
- 改善测试框展开和按钮反馈，避免输入时反复重算高度，保留调整文本框高度与键盘排序操作。

## 编译与报错修复

- 修复大文件暂停实时检查后，修改代码仍保留旧编译错误的问题；覆盖 LightCP、经典 IDE、Sublime 三种界面。
- 相关头文件即使没有打开为标签，外部修改、删除、重建或改名也会使旧构建诊断失效，并对打开的主文件重查。无关文件变化和自己的保存回声不会清除有效诊断。
- 构建结果返回前会校验实际依赖和外部变化，阻止运行已过期的程序；相关文件在编译期间打开、修改或保存时也会检查内容。
- 预处理失败时保留已知依赖；无法完整确认输入时保留原始输出、显示明确的构建提示，避免将旧磁盘报错误定位到当前编辑器。
- 正确解析 GCC 混合/多行/截断 JSON、宏诊断及 Clang 文本诊断；区分真正的链接失败与报错文字中出现的链接术语。
- 修复 `-MP` 依赖清单中的空伪目标导致应用误判构建失败的问题。
- 探测并缓存编译器的结构化诊断能力，修复 `c++` 等 GCC 别名遇到 Tab 时定位偏移；正确处理列原点、UTF-16、中文、emoji、BOM 和换行。
- 保留预处理校验后的构建复用，拒绝直接运行失效构建。当前入口仍为单个 `.cpp`，额外源码和 `@响应文件` 参数会明确提示暂不支持。

## 下载与更新

- 安装版：`LightCP_0.1.1-dev.14_x64-setup.exe`。
- 便携版：`LightCP_0.1.1-dev.14_x64-portable.exe`，下载后直接运行。
- 题目导入脚本：`lightcp-codeforces.user.js`，支持 CF / 洛谷题目页 F10 导入。
- `SHA256SUMS.txt` 包含本次三个下载文件的校验值。

需要 Windows 10/11、Microsoft Edge WebView2 Runtime，以及用于编译/调试/语言服务的 g++、GDB、clangd。请先保存代码、退出旧版本，再运行新版或安装包。预览版用户也可在“设置 → 关于与更新”检查此版本。
