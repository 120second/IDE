# LightCP v0.1.1-dev.15

Windows 开发预发布版，2026-10-23。修复 GitHub CI 的 GCC 16 工具链兼容问题，保留 [dev.14](v0.1.1-dev.14.md) 的界面与编译诊断改进。

## 本次修复

- 缓存预处理与实际构建统一探测诊断格式，GCC 16 不再收到已移除的 `-fdiagnostics-format=json` 参数，恢复其重复构建的校验与复用路径。
- 不支持旧 JSON 的 GCC 改用经过探测的文本模式，固定字节列和列原点，再转换为编辑器 UTF-16 坐标；保留 Tab、中文、emoji、BOM 的正确定位。支持旧 JSON 的 GCC 与 Clang 继续使用各自兼容路径。
- 诊断能力缓存区分具体探测参数，预处理总超时包含能力检测耗时。
- CI 记录工具链版本与测试输出；缓存测试同时验证命中与明确启用的安全重编译路径，并检查实际程序结果及相关头文件变化。

GCC 官方说明：旧 JSON 格式在 GCC 15 废弃，并于 [GCC 16 移除](https://gcc.gnu.org/pipermail/gcc-patches/2025-June/688117.html)。文本字节列使用 [GCC 诊断列单位选项](https://gcc.gnu.org/onlinedocs/gcc/Diagnostic-Message-Formatting-Options.html)。
