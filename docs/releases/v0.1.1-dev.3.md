# LightCP v0.1.1-dev.3

Windows 开发预发布版，发布于 2026-10-08。本次更新改善随机数据配置，并新增 CF / 洛谷题目监听导入。

## 本次更新

- 新建测试点的表单显示在现有测试点列表底部；点击新建后滚动到表单。
- 新增 CF / 洛谷题目监听。安装配套油猴脚本并在 IDE 开启监听后，当前可见的题目自动创建使用竞赛模板的 C++ 文件，同时保存 Markdown 题面、关联读题面板并添加固定样例。
- 洛谷优先使用已有中文题面，支持站内切题。同一来源重复导入会打开已有代码；不会覆盖已有解答。
- 随机数据采用左侧配置、右侧预览的布局。数组、区间查询、树、图、矩阵、字符串、排列、整数行可一键套用，多组测试 T 可直接勾选，主参数默认展开编辑。
- 范围、长度和循环次数支持 `3n`、`3*n`、`n*m`、`(n+1)/2` 等加减乘除、取余和括号表达式，也支持 `1e9` 和 `10^9`。整数运算按 int64 精确处理；除法向零取整。除零、溢出和未定义变量会提示错误。
- 兼容之前保存的 `3n` 等表达式草稿；支持同行批量添加变量及整数与数组同行输出。
- 默认每次生成使用新种子，固定种子可复现。运行当前预览时直接使用选中的输入；切换文件或编辑规则后不再显示过期的异步生成结果。
- 在生成前提示范围填反等错误，保存失败也会显示原因。

## 下载与使用

- 安装版：`LightCP_0.1.1-dev.3_x64-setup.exe`。
- 便携版：`LightCP_0.1.1-dev.3_x64-portable.exe`，下载后直接运行。
- 油猴脚本：`lightcp-codeforces.user.js`，同一脚本同时支持 CF 和洛谷。旧版脚本需更新到 1.1.0 并刷新题目页。
- `SHA256SUMS.txt` 提供上述文件的 SHA-256 校验值。

需要 Windows 10/11 与 Microsoft Edge WebView2 Runtime。编译、调试和 C++ 语言服务分别需要 g++、GDB 与 clangd，可在设置中配置路径。

监听使用方式见 [CF / 洛谷题目监听](https://github.com/120second/IDE/blob/v0.1.1-dev.3/docs/codeforces-import.md)，输入规则示例见 [随机数据说明](https://github.com/120second/IDE/blob/v0.1.1-dev.3/docs/random-generator.md)。监听仅在开启时绑定本机回环地址 `127.0.0.1:27121`；洛谷有中文翻译时优先使用中文，不执行自动翻译。
