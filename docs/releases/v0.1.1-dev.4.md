# LightCP v0.1.1-dev.4

Windows 开发预发布版，发布于 2026-10-16。本次更新将 CF / 洛谷题目导入改为按 F10 触发，并自动准备工作区接收服务。

## 本次更新

- 在 LightCP 打开工作区后，直接在浏览器的 CF 或洛谷题目页按 F10，即可创建 C++ 文件、保存 Markdown 题面、打开读题面板并添加固定样例，无需手动开启监听。
- 打开、刷新、切换题目页以及点击页面提示均不会自动导入。带修饰键的组合键、长按重复按键不会触发，发送中的重复按键会合并处理。
- 默认使用竞赛 C++ 模板，可在「题目导入」设置中更换；当前会话切换工作区后保留所选模板。
- 切换工作区时自动关闭旧接收会话并为新目录准备接收，防止题目写入旧目录；连接失败时可以重试。
- 配套油猴脚本更新至 1.2.1。新版接收服务拒绝旧脚本的自动导入请求；洛谷站内切题后按 F10 会读取当前题目。
- 继续支持优先读取洛谷已有中文题面，以及重新打开已导入题目而不覆盖已有解答。

## 下载与使用

- 安装版：`LightCP_0.1.1-dev.4_x64-setup.exe`。
- 便携版：`LightCP_0.1.1-dev.4_x64-portable.exe`，下载后直接运行。
- 油猴脚本：`lightcp-codeforces.user.js`，同一脚本同时支持 CF 和洛谷。
- `SHA256SUMS.txt` 提供上述文件的 SHA-256 校验值。

已安装旧版脚本的用户请更新至 **1.2.1**，停用重复安装的旧脚本，并刷新所有已打开的题目页。F10 需要在浏览器题目页获得焦点时按下。

需要 Windows 10/11 与 Microsoft Edge WebView2 Runtime。编译、调试和 C++ 语言服务分别需要 g++、GDB 与 clangd，可在设置中配置路径。

详细步骤见 [CF / 洛谷题目导入说明](https://github.com/120second/IDE/blob/v0.1.1-dev.4/docs/codeforces-import.md)。
