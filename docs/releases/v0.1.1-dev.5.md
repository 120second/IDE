# LightCP v0.1.1-dev.5

Windows 开发预发布版，发布于 2026-10-20。

## 本次更新

- 新增本地待刷题待办：记录题目名称、链接和备注，支持搜索、编辑、完成筛选、删除与撤销，离线可用。
- 新增「设置 → 关于与更新」，可检查官方 GitHub Release、查看更新说明并下载安装版或便携版；预览版与正式版按各自更新通道检查。
- 新增经典 IDE 界面、顶部菜单和代码缩略图；测试框支持单独选择标准布局或经典紧凑双栏。
- 随机数据支持粘贴样例识别输入结构，调整范围并关联数组、树、询问数量，支持多组测试、歧义选择和恢复之前的格式。
- 改进编译诊断、错误定位、编译运行状态与取消处理，以及 clangd 增量同步和函数参数提示。
- 登录时可选择记住登录 30 天并在下次启动时自动登录；凭证保存在系统凭据库，不勾选时仅本次运行有效。

## 下载与使用

- 安装版：`LightCP_0.1.1-dev.5_x64-setup.exe`。
- 便携版：`LightCP_0.1.1-dev.5_x64-portable.exe`，下载后直接运行。
- 题目导入油猴脚本：`lightcp-codeforces.user.js`，支持在 CF / 洛谷题目页按 F10 导入。
- `SHA256SUMS.txt` 提供以上文件的 SHA-256 校验值。

需要 Windows 10/11 与 Microsoft Edge WebView2 Runtime。编译、调试和 C++ 语言服务分别需要 g++、GDB 与 clangd，可在设置中配置路径。更新前请保存代码并退出旧版应用。
